# LearnOOP

Проект для изучения объектно-ориентированного программирования (ООП) на Python.

## Описание

Этот проект содержит примеры и упражнения для изучения основных концепций ООП:
- Классы и объекты
- Наследование
- Инкапсуляция
- Полиморфизм

## Требования

- Python 3.13+
- `uv` (менеджер зависимостей)

## Запуск

```bash
# 1) Скопируй пример и вставь токен бота
cp env.example .env
# отредактируй .env и укажи BOT_TOKEN

# 2) Установи зависимости и запусти эхо-бота
uv run python bot.py
```
